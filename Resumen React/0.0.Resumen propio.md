
Crear desde VSCode la estructura del proyecto de React.

`npm create vite@latest`

Esto dispara las consultas de configuración del proyecto.

- El framework, se selecciona REACT.
- El secundario se elige Javascript plano...para usar JS vanilla y JSX.

finalmente, si no da ningún error, el proyecto ya inicia levandado con un puerto asignado.

Index.html tiene un único objeto DOM div con id="root". 
ahi se montará toda la app de React.

el script llama justamente a la obtención de ese elemento mediante javascript, y aplicar el codigo que figura en `main.jsx`.

`main.jsx` importa la función `createRoot()` y se define el objeto con `id=root` para renderizar el codigo jsx siguiente:
```jsx
<StrictMode>
<App />
</StrictMode>
```

dentro del ==componente== *App* está toda nuestra web.

Un **componente** justamente es una función que retorna una `estructura html` declarada en `jsx`

>[!warning] IMPORTANTE
>El nombre de los componentes SIEMPRE va definido con mayúscula

```jsx
const Componente1 = ()=>{
	return (
	<h1> Hola Mundo </h1>
	)
}
```

#### Pasarle propiedades a los componentes
Esa función, como todas en js, puede tener otros statementes a realizar antes de retornar el componente.
También se puede pasarle "*propiedades*"(props) al utilizarlo en nuestro componente App(o cualquier otro) y hay que tener en cuenta que el componente (función) SIEMPRE recibe un objeto con esas props que pasamos al utilizarlo.
Hay que desestructurar, o recordar que las props forman parte de un objeto, para usarlas.

ejemplo:
```jsx
const App = ()=>{
	return(
		<Componente2 nombre="John" />
	)
}
```

y al definir el componente, desestructuro lo que llega...
```jsx
const Componente2 = ({ nombre })=>{
return (
	<h1> Buen día {nombre}</h1>
)
}
```

Todo el código entre llaves es "evaluado" en JS antes de presentarlo.

#### Orden de los imports en un proyecto de React

La convención es la siguiente:
```js
//1. Dependencias externas 
import React, { useState, useEffect } from 'react'; 
import { Link, useNavigate } from 'react-router-dom'; 
import axios from 'axios'; 

//2. Dependencias internas (Módulos, hooks, utilidades) 
import { useAuth } from '@/hooks/useAuth';
import { formatCurrency } from '@/utils/helpers'; 
import { API_URL } from '@/config/constants'; 

//3. Componentes 
import Sidebar from '@/components/layout/Sidebar'; 
import CustomButton from '@/components/ui/CustomButton'; 
import LocalCard from './components/LocalCard'; //Componente del mismo directorio 

// 4. Multimedia y datos estáticos 
import logoImg from '@/assets/images/logo.png'; 
import mockData from '@/assets/data/lessons.json';
```


#### Asignar clases a los componentes
Para darle estilos a los componentes, podemos definir, dentro del _return_ del mismo, la *clase*, o *id*, o cualquier otro atributo que deba tener el mismo.

```jsx
const componente1 = ()=>{
return (
	<h1 class="headerH1" id="titulo1"> Hola desde React</h1>
)
}
```
