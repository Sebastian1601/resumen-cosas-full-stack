
Crear desde VSCode la estructura del proyecto de React.

`npm create vite@latest`

Esto dispara las consultas de configuración del proyecto.

- El framework, se selecciona REACT.
- El secundario se elige Javascript plano...para usar JS vanilla y JSX.

finalmente, si no da ningún error, el proyecto ya inicia levandado con un puerto asignado.

Index.html tiene un único objeto DOM div con id="root". 
ahi se montará toda la app de React.

el script llama justamente a la obtención de ese elemento mediante javascript, y aplicar el codigo que figura en `main.jsx`.

`main.jsx` importa la función `createRoot()` y se define el objeto con `id=root` para renderizar el codigo jsx siguiente:
```jsx
<StrictMode>
<App />
</StrictMode>
```

dentro del ==componente== *App* está toda nuestra web.

Un **componente** justamente es una función que retorna una `estructura html` declarada en `jsx`

>[!warning] IMPORTANTE
>El nombre de los componentes SIEMPRE va definido con mayúscula

```jsx
const Componente1 = ()=>{
	return (
	<h1> Hola Mundo </h1>
	)
}
```

#### Pasarle propiedades a los componentes
Esa función, como todas en js, puede tener otros statementes a realizar antes de retornar el componente.
También se puede pasarle "*propiedades*"(props) al utilizarlo en nuestro componente App(o cualquier otro) y hay que tener en cuenta que el componente (función) SIEMPRE recibe un objeto con esas props que pasamos al utilizarlo.
Hay que desestructurar, o recordar que las props forman parte de un objeto, para usarlas.

ejemplo:
```jsx
const App = ()=>{
	return(
		<Componente2 nombre="John" />
	)
}
```

y al definir el componente, desestructuro lo que llega...
```jsx
const Componente2 = ({ nombre })=>{
return (
	<h1> Buen día {nombre}</h1>
)
}
```

Todo el código entre llaves es "evaluado" en JS antes de presentarlo.

```js
//1. Dependencias externas

```


#### Asignar clases a los componentes
Para darle estilos a los componentes, podemos definir, dentro del _return_ del mismo, la *clase*, o *id*, o cualquier otro atributo que deba tener el mismo. Esto se hace pasando como prop `className` y el nombre de la clase a asignar.

>Ejemplo
```jsx
const componente1 = ()=>{
return (
	<h1 className="headerH1" id="titulo1"> Hola desde React</h1>
)
}
```

### Crear listas dinámicas en React
Al presentar páginas, vamos a tener seguramente que generar listados con elementos dinámicos que vienen de una base de datos u otra estructura de datos.
```js
const ListadoClientes= ()=>{

const lista = [
{id:65423,nombre:"ernesto Juarez" , direccion:"calle1" , email: , dni:23658013 },
{id:5631,nombre:"Alberto Pipino" , direccion:"calle2" , email: , dni: 45321680},
{id:6538,nombre:"Rocio Marniz" , direccion: "callen", email: , dni: 65904125},
{id:68510,nombre:"Estela Ramirez" , direccion: "calledsa", email: , dni: 65934120},
];

return (
	<div className="container">
	<ul>
	//abrimos llaves para evaluar el array que nos devolverá map
	{
		lista.map((cliente)=>(
			<li key="{cliente.id}">`${cliente.nombre} - ${cliente.direccion} - ${cliente.email}`</li>
		))
	}
	</ul>
	</div>
)
```

Esto nos devolverá la estructura que listará los clientes en filas de una *lista no-ordenada*.
Siempre debemos, al crear una lista, asignar un prop llamado `key` que normalmente debe ser un *valor único* para identificar ese "*registro*" que estamos mostrando en nuestra página.
En este caso, al ser una propiedad directamente llamada id, podemos asignarle esa a cada item `<li>` que estamos devolviendo.

### React Router
React router permite crear SPA's donde la navegación se realiza en la misma pantalla, sin recargar toda la web completa. Esto se da gracias a la característica de React de recargar componentes al vuelo.

Este modulo es la base para otros que son especializados para la navegación web como `react-router-dom`.

Para aplicarlo, vamos a hacer uso de 4 metodos de `react-router` que viene instalado por defecto al inicializar el proyecto de React con Vite.
- `BrowserRouter` de `react-router`
- `Route` de `react-router`
- `Routes` de `react-router`
- `Link` de `react-router`
- `NavLink` de `react-router`

----
### Rutas
#### Usando react-router-dom
Este es un módulo específico con hooks y propiedades para utilizar específicamente para la navegación web.

Lo que hace es relacionar direcciones web con la presentación y dibujado de componentes(*componentes del nivel de una página*).

Para hacer uso se instala como cualquier módulo de Nodejs.
`npm install react-router-dom`

Primero importamos `createBrowserRouter` en la definición del componente **App**
```js
import { createBrowserRouter } from 'react-router-dom';

const router = createBrowserRouter([]);

createRoot(document.getElementById("root")).render(
	<StrictMode>
		<App />
	</StrictMode>
);
```

createBrowserRouter trabaja con la API del historial de páginas del navegador. Aqui vamos a definir nuestro paths para renderizar las distintas páginas.

```js
const router = createBrowserRouter([
{ path: "/", element: <App />},
])
```
Esto indica que en la ruta raíz de nuestro dominio, vamos a renderizar el componente `<App/>`

Asi podemos crear distintas páginas con sus rutas muy fácil.
Agreguemos una página sobre un *dashboard* y otra sobre *about*(estos, finalmente serán componentes que deberemos definir y exportar luego en cada uno de sus archivos).

```js
const router = createBrowserRouter([
{ path: "/", element: <App />},
{ path: "/dashboard", element: <Dashboard />},
{ path: "/about", element: <About />},
])
```
Tan simplemente con eso, definimos el acceso a nuestras otras secciones.

1. Como teníamos definido en nuestro archivo principal, el renderizar el componente `<App />`, lo vamos a cambiar por el otro método que debemos importar llamado `RouterProvider`

2. Aparte, le vamos a pasar como prop, la constante que definimos como `router` con el array de objetos de rutas y componentes a vincular.

```js
import { createBrowserRouter } from 'react-router-dom';
import { RouterProvider } from 'react-router-dom';

const router = createBrowserRouter([
{ path: "/", element: <App />},
{ path: "/dashboard", element: <Dashboard />},
{ path: "/about", element: <About />},
]);

createRoot(document.getElementById("root")).render(
	<StrictMode>
		<RouterProvider router={ router } /> 
		//reemplazamos <App /> por < RouterProvider />
	</StrictMode>
);
```

De esta manera, si tenemos las páginas definidas en sus rutas, vamos a poder navegarlas normalmente, excepto que ingresemos un path que no esté definido. De ser así, el navegador nos mostrará un error 404, indicándo que la página no existe.
Podemos manejar esto de manera más profesional, creando una página 404 e indicando que cualquier camino que no esté registrado en nuestro router, llegue a nuestra página propia de 404.

Para eso, podemos crear un componente llamado `NotFoundPage` y definimos de la siguiente manera el mismo
```js
const NotFoundPage = ()=> {
	return (
	<div>
		<h1> Not Found Page </h1>
		<Link to={"/"}>
			<button> Go Back Home </button>
		</Link>
	</div>
	);
};
```

Pero aqui, estamos usando otro componente que no habíamos definido antes, llamado `Link`.
Link pertenece a `react-router-dom` y nos permite crear un vínculo con lo que hay dentro del mismo, que enlaza con la ruta que definimos como prop en `to={"/"}`, por lo que este vínculo que envuelve a un botón html, nos llevará de nuevo a **home**.

```js
import { Link } from 'react-router-dom';

const NotFoundPage = ()=> {
	return (
	<div>
		<h1> Not Found Page </h1>
		<Link to={"/"}>
			<button> Go Back Home </button>
		</Link>
	</div>
	);
};
```

Para usar esta página personalizada de NotFound, definimos un comodin como ruta en donde creamos el `BrowserRouter`
```js
import { createBrowserRouter } from 'react-router-dom';
import { RouterProvider } from 'react-router-dom';
import { App, Dashboard, About, NotFoundPage } from '../views/pages.jsx'

const router = createBrowserRouter([
{ path: "/", element: <App />},
{ path: "/dashboard", element: <Dashboard />},
{ path: "/about", element: <About />},
//agregamos aqui la ruta general luego de las demas
{ path: "*", element = <NotFoundPage />}
]);

createRoot(document.getElementById("root")).render(
	<StrictMode>
		<RouterProvider router={ router } /> 
		//reemplazamos <App /> por < RouterProvider />
	</StrictMode>
);
```

#### Rutas dinámicas
Las rutas dinámicas nos permiten cargar ciertas páginas, utilizando los datos enviados por URL para filtrar y presentar los datos.

normalmente podemos usar el dynamicRouting de la siguiente manera, en nuestro ya definido `BrowserRouter`

```js
import { createBrowserRouter } from 'react-router-dom';
import { RouterProvider } from 'react-router-dom';
import { App, Dashboard, About, NotFoundPage } from '../views/pages.jsx'

const router = createBrowserRouter([
{ path: "/", element: <App />},
{ path: "/dashboard", element: <Dashboard />},
{ path: "/about", element: <About />},

//ruta dinámica definida
{ path: "dashboard/:id", element <DashboardItems />}

//agregamos aqui la ruta general para manejar los 404, luego de las demas
{ path: "*", element = <NotFoundPage />}
]);

createRoot(document.getElementById("root")).render(
	<StrictMode>
		<RouterProvider router={ router } /> 
		//reemplazamos <App /> por < RouterProvider />
	</StrictMode>
);
```

Luego, podemos definir nuestro componente `Dashboard` y lo que representa `DashboardItems`
Este componente Dashboard, va a listar nuestro arreglo de elementos definido como `dashboardItems` (*PERO ESTE NO ES EL COMPONENTE*)
```js
const Dashboard = ()=> {
	const dashboardItems = [
		{ id: 1, title: "My Profile",},
		{ id: 2, title: "My Projects",},
		{ id: 3, title: "My Teams",},
	];
	
	return (
		<div>
			<h1> Dashboard Page </h1>
			<ul>
				{
				dashboardItems.map((item)=> (
					<li key={item.id}>
						<Link to={`/dashboard/${item.id}`}>
						<h2> { item.title } </h2>
						</Link>
					</li>
				))
				}
			</ul>
	)
};

export default Dashboard;
```

Pero, de donde sale el componente `dashboardItems`? lo vamos a crear ahora.
Para eso vamos a utilizar `useParams` desde `react-router-dom`:
```js
import { useParams } from 'react-router-dom';

const DashboardItems = ()=>{
	const { id } = useParams();
	
	return (
		<div>
		 <h1> Dashboard Items { id } </h1>
		</div>
	);
};

export default DashboardItems
```

`useParams()` devuelve un objeto con los parámetros pasados a la dirección URL definida en nuestro `browserRouter`.

esto es:
```js
const parametros = useParams();
//parametros termina siendo:
//  {
//  	id:"1"
//  }
```

### hook: useEffect()
Este hook de React, permite ejecutar código arbitrario, cuando:
- el componente se monta en el DOM
- cada vez que cambia la o las dependencias vinculadas

*Arbitrario*: definido por el desarrollador

El hook recibe 2 parámetros, el callback a ejecutar, y el arreglo de dependencias el cual evalua para detectar cambios y ejecutarse.
`useEffect( callback, [lista_de_dependencias]`

La lista de dependencias suelen ser variables, objetos, arrays, etc.

>Ejemplo
```js
import { useState, useEffect } from 'react';

const Componente = ()=>{
	const [value, setValue] = useState(false)
	
	useEffect(() =>{
	console.log("useEffect Ejecutado");
	},[])
}
```

Normalmente el `useEffect` se ejecuta *COMO MINIMO* 1 vez.

La lista de dependencias es OPCIONAL, pero esto contrae ciertas características en el funcionamiento del `useEffect`

>Si NO pasamos lista de dependencias:
- el código se ejecutará cada vez que el componente se renderice. (tener en cuenta que si se renderiza un componente padre, este componente se renderiza también, por lo tanto, el codigo se vuelve a ejecutar...)
>Si pasamos un **array vacío** `[]` :
- el código del callback se ejecutará solamente al montar el componente, una sola vez.

>Si definimos una dependencia o lista de dependencias
- El código se ejecutará cada vez que se detecte un cambio en la dependencia.

>Ejemplo
```js
import { useState, useEffect } from 'react';

const Componente = ()=>{
	//definimos la variable nombre, e inicializamos en vacío.
	const [nombre, setNombre ] = useState("");
	
	//luego, definimos el useEffect
	useEffect(( )=>{
		if (nombre.length < 4) {
		console.log("El nombre debe tener al menos 5 digitos", nombre);}
	}, [nombre])
	
	return (
		<form onSubmit={handleSubmit}>
		<label for="nombre">
		<input 
			name="nombre",
			onChange={(e)=> setNombre(e.target.value)}
			/>
		</label> 
	)
	
	}
```

Esto, lo que logra es que cada vez que estemos escribiendo por ejemplo nuestro nombre en un campo input, la consola analice si el mismo (falta codigo restante) tiene más de 4 digitos. Si es menos, se imprime el `console.log()`

### fetching datos
Para listar datos, normalmente vamos a hacer un fetch(), y listarlos.
Esto lo hacemos en el componente que se encarga de listar los elementos directamente, en este caso, el dashboard.
Para ejecutar este codigo de fetch la vez que el componente dashboard se monta, usamos useEffect( ) con la lista de dependencias vacía, para la ejecución única al iniciar el componente.

```js
import { useEffect } from 'react'

const Dashboard = ()=>{
	const [users, setUsers] = useState([]) //inicio el estado con un array vacio
	
	useEffect(()=>{
		fetch("https://jsonplaceholder.typicode.com/users")
		 .then((response)=> response.json())
		 .then((data)=> setUsers(data))
		 .catch((error)=> console.error("Error fetching users", error));
	}, []);
	
	return(
		<div>
			<h1> User Dashboard </h1>
			 <ul>
			 {users.map((user)=>(
					 <li key={user.id}>
					 <Link to={`/dashboard/${user.id}`}>
					 <h2>{user.name}</h2>
					 </Link>
					 </li>
			 ))}
			 </ul>
			 </div>
	);
};

export default Dashboard;
```

Luego, podemos crear un nuevo componente **DashboardItems** que retorne las listas  `TO DO`  del cliente en particular...

```js
const DashboardItems =()=>{
	const {id} = useParams(); //obtenemos la ID del usuario de la URL
	const [todos, setTodos] = useState([]);
	
	useEffect(()=>{
		fetch(`https://jsonplaceholder.typicode.com/users/${id}/todos`)
		 .then((response)=> response.json())
		 .then((data)=> setTodos(data))
		 .catch((error)=> console.error("Error fetching todo data", error));
	}, [id]);
	
	return (
		<div>
			<h1> User Todos </h1>
			<ul>
			{todos.map((todo)=>(
				<li key={todo.id}>
				<h3>{todo.title}</h3>
				<p> Status: {todo.completed? "Completed":"Pending"}</p>
				</li>
			))}
			</ul>
		</div>
	);
};
```
